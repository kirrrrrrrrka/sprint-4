# sprint-4 / Тестирование класса BooksCollector

## Описание тестов

### test_add_new_book_add_two_books
Пример теста из задания - проверяет добавление двух разных книг

### test_add_new_book_with_different_lengths
Проверяет добавление книг с различной длиной названия (от 1 до 40 символов, а также граничные случаи)

### test_set_book_genre_validation
Проверяет установку валидных и невалидных жанров для книг

### test_get_books_for_children_filtering
Проверяет фильтрацию книг для детей (исключение жанров с возрастным рейтингом)

### test_favorites_operations
Проверяет операции с избранными книгами (добавление, защита от дубликатов)

### test_delete_from_favorites
Проверяет удаление книги из избранного

### test_get_books_with_specific_genre
Проверяет получение книг с определенным жанром

### test_no_duplicate_books
Проверяет защиту от добавления дубликатов книг

### test_complete_workflow
Проверяет комплексный рабочий процесс с разным количеством книг

### test_get_book_genre
Проверяет получение жанра существующей и несуществующей книги

### test_set_genre_for_existing_and_nonexisting_book
Проверяет установку жанра для существующей и несуществующей книги
